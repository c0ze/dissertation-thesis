\addcontentsline{toc}{section}{Foreword}

My original dissertation thesis in 2004 was incomplete. This has been bugging me for a while, so I decided to revamp it using AI.

I stayed true to the state of facts as of 2004 in the historical and introductory chapters, filled in the missing algorithms, sketched the implementation strategy that the parallel simulator should have used, and made the build itself easier to execute in 2026. The exceptions are Sections~\ref{sec:parallel} through~\ref{sec:shor}: the implementation strategy in Section~\ref{sec:parallel} is informed by what the simulator community has converged on since 2004, and the algorithm chapters draw on later expository work (Kitaev's phase estimation, Beauregard's $2n+1$-qubit Shor circuit, qHiPSTER's distributed state-vector design, the Harrow--Hassidim--Lloyd linear-systems algorithm) that did not exist when the original thesis was submitted.
